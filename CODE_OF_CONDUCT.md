# Community guidelines

## The short version

Be decent. Assume the other person is trying to build something good.

## What that means here

This project is mostly about evidence: measurements, counterexamples, and
things that turned out not to be true. That only works if people can be wrong
in public without it costing them anything.

**Expected:**

- Disagree with the work, not the person. "This benchmark does not control for
  X" is a contribution. "You clearly don't understand benchmarking" is not.
- Say what you measured. A claim with a method attached can be checked; one
  without it can only be argued about.
- Accept being corrected. Several sections of this repository exist because a
  confident conclusion turned out to be wrong, and saying so was the useful
  part.
- Assume good faith in ambiguous wording, especially from people writing in a
  second language.

**Not acceptable:**

- Harassment, insults, or personal attacks of any kind.
- Discrimination or demeaning comments relating to age, disability, ethnicity,
  gender identity or expression, nationality, personal appearance, race,
  religion, or sexual orientation.
- Publishing anyone's private information without their explicit permission.
- Sustained disruption of discussions, or deliberately bad-faith argument.

## Scope

These guidelines apply in the issue tracker, in pull requests, in commit
messages and in any space where someone is representing this project.

## If something goes wrong

Report it to the maintainer at the address on the GitHub profile for
[@akshatinnovate-png](https://github.com/akshatinnovate-png). Reports are
handled privately.

Maintainers are expected to act on reports, and to apply these guidelines to
themselves first. Consequences scale with what happened: usually a request to
stop, sometimes a temporary block, and for serious or repeated behaviour, a
permanent one.
